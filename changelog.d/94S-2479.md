### 운영자가 할 일

- **워크스페이스 MCP 서버를 인증 없이(`auth_kind` `none`) 등록할 수 있다.** 공개 MCP 서버에 가짜 token을 넣지 않아도 되고, 그 서버의 호출에는 Authorization 헤더가 실리지 않는다. migration `0395_workspace_mcp_auth_none`이 `workspace_mcp_servers`의 CHECK를 넓히며 행은 다시 쓰지 않는다. 올릴 때 따로 할 일은 없다.
  - 되돌리기 하한: `none` 서버를 등록한 DB는 이 값을 모르는 판보다 앞선 이미지(워크스페이스 MCP 서버 목록이 모르는 인증 방식을 받기 전의 판)로 되돌리지 않는다. 그 이미지는 서버 목록을 500으로 답한다. 바로 앞 판은 그 서버를 "지원하지 않는 인증"으로 보이고 호출에 아무 자격도 싣지 않는다.
