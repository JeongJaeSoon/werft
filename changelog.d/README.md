# 변경 기록 조각

PR마다 이 디렉터리에 조각 파일을 하나 둔다. `CHANGELOG.md`는 직접 고치지 않는다. 릴리스 PR이 `bun .github/scripts/changelog-release.ts vX.Y.Z`로 조각을 모아 `CHANGELOG.md`에 `## vX.Y.Z` 절을 만들고 조각을 지운다.

- 파일 이름은 `<티켓>.md`다(Linear 티켓 키, 예: `ABC-1234.md`). 티켓이 없으면 PR 번호를 쓴다. 영문자·숫자로 시작하고 영문자·숫자·`.`·`_`·`-`만 쓴다. `.md`가 아닌 파일은 둘 수 없다.
- 무엇을 쓰는지는 `CHANGELOG.md`의 "쓰는 방식"을 따른다. 설치하거나 올리는 사람이 꼭 읽어야 할 것이 없는 PR은 조각을 두지 않는다.
- 절 아래의 줄은 모두 항목(맨 앞이 `- `)이거나, 그 아래에 두 칸 이상 들여 쓴 줄이거나, 빈 줄이다. 절은 항목으로 시작하고, 절 안에는 빈 줄을 두지 않는다(합친 목록이 느슨해져 다른 항목의 모양이 바뀐다). `- - -` 같은 구분선과 항목 안의 제목(`## …`, `===`·`--` 밑줄)도 쓰지 않는다. 코드 펜스는 항목 아래에 정확히 두 칸 들여 쓴 자기 줄에서 열고, 펜스 안의 줄은 펜스만큼 들여 쓴다. 목록 표식(`-`, `1.` 등) 뒤에는 공백 한 칸만 두고, 들여쓰기는 공백으로만 한다. 탭은 쓰지 않는다. 펜스를 여는 줄에는 언어 이름 하나만 쓴다. 대괄호로 시작하는 문단, 제어 문자와 줄 구분 문자도 쓰지 않는다.
- 안에는 `### 보안`과 `### 운영자가 할 일` 가운데 쓸 절만 두고, 그 아래에 항목을 `CHANGELOG.md`와 같은 꼴로 쓴다. 절마다 항목이 하나 이상 있어야 한다. 그 밖의 제목(`#`으로 시작하는 줄)과 첫 절 앞의 글은 둘 수 없다. 코드 펜스는 연 줄과 같은 들여쓰기·문자로 닫고, 펜스 안에는 `#`으로 시작하는 줄과 다른 펜스 표식을 두지 않는다. 인용문(`>`), HTML(주석과 본문 중간의 태그 포함. `<https://…>` 자동 링크는 된다)과 `` \` ``·`\[`·`\]` 같은 이스케이프도 쓰지 않는다. 이 제한은 합친 파일에서도 조각이 같은 모양으로 보이게 하려는 것이다. 줄 끝은 LF다. 링크는 본문 안에 절대 URL(`https://…`)로 쓴다. 조각은 저장소 맨 위의 `CHANGELOG.md`로 옮겨지므로 상대 경로는 거절한다. 참조 정의(`[이름]: URL`)도 거절한다. 두 조각이 같은 이름을 쓰면 합친 파일에서 앞의 정의가 둘 다에 걸리기 때문이다.
- 항목에는 PR 링크(`JeongJaeSoon/werft#123`)를 붙인다. PR을 연 뒤 번호를 넣는다.

```markdown
### 운영자가 할 일

- **바뀐 것을 한 문장으로 쓴다**(JeongJaeSoon/werft#123). 올릴 때 할 일과 되돌릴 수 있는지를 쓴다.
  - 덧붙일 것은 들여 쓴 항목으로 쓴다.
```

모을 때 조각은 파일 이름의 역순(티켓 번호가 큰 것부터)으로, "미출시" 절의 항목보다 앞에 온다. `tests/release-auto.test.ts`가 이 디렉터리의 조각과 "미출시" 절이 이 형식인지 확인한다.
