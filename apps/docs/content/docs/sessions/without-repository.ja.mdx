---
title: "リポジトリなしのセッション"
description: リポジトリを clone せず、空の作業スペースで動くセッション
---

セッションは `repository_id` を送ればそのリポジトリを clone し、省けばリポジトリなしの空の作業スペースから始められる。リポジトリはワークスペースの上限とエージェントの GitHub 設定の範囲内でなければならない。SDK の例は [SDK のインストール](/getting-started/install#クライアントを作る)で作った `werft` クライアントを、HTTP API の例はサーバーのアドレス `API` とキー `KEY` のシェル変数を使う。

## リポジトリなしで作る

`repository_id` を省いて作る。

<Tabs groupId="client" persist items={["SDK", "HTTP API"]}>
<Tab>

```ts
const created = await werft.sessions.create({
  agent_release_id: process.env.WERFT_AGENT_RELEASE_ID ?? "",
  message: 'GATE-SPEC {"id":"no-repo","steps":[],"final":"no repository here"}',
});
console.log(created.status);
const session = await werft.sessions.get(created.session_id);
console.log(session.repository_id, session.repository);
```

```text
queued
null null
```

</Tab>
<Tab>

```bash
NOREPO=$(curl -sS "$API/v1/sessions" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --arg m 'GATE-SPEC {"id":"no-repo","steps":[],"final":"no repository here"}' \
    '{agent_release_id: env.WERFT_AGENT_RELEASE_ID, message: $m}')" | jq -r .session_id)
curl -sS "$API/v1/sessions/$NOREPO" -H "Authorization: Bearer $KEY" | jq -c '{repository_id, repository}'
```

```text
{"repository_id":null,"repository":null}
```

リファレンス: [`POST /v1/sessions`](/reference/http-api/sessions/createSession)

</Tab>
</Tabs>

リポジトリがないので、push する先もない。このセッションの [push リクエスト](/approvals/request)は 409 `PUSH_SOURCE_MISSING` になる。

## エージェントのセッションはリポジトリなしで始まる

[エージェント](/agents/create#セッションに紐付ける)のリリースで作ったセッションで `repository_id` を省くと、GitHub 設定があるエージェントはリポジトリなしで始まる。例外ではなく、エージェントのセッションの既定の動きである。エージェントは許可されたリポジトリを `list_repositories` で見て、タスクが読むか変更するリポジトリだけを `attach_repository` で付ける([セッションの途中でリポジトリを付ける](/integrations/github#セッションの途中でリポジトリを付ける))。付けたリポジトリは作業スペースに git リモートとして入り、そこへの書き込みはリポジトリごとに push 要求 1 回ずつの[承認](/approvals/request)を通る。

リポジトリのないセッションで、成果物として集めたいファイルは作業スペースのルートの `out/` に置く。checkpoint がその下のファイルを成果物として集める。`repository_id` を送ればそのリポジトリで始まり、GitHub 設定がまだない古いエージェントはリリースのリポジトリで始まる。
