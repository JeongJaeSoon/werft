## 学習

Werft は、Slack で読んだメッセージでどの AI モデルも学習させない。

エージェントはこの組織が接続したモデルキーでモデルを呼び出す。モデルに送ったメッセージは、そのモデル提供元のデータポリシーに従う。

## 読むメッセージ

- **エージェントへの依頼。** エージェントをメンションしたメッセージ、エージェントに送った DM(**DM を受け取る**がオンの場合)、エージェントの作業(セッション)が続くスレッドに書いたメッセージは作業の依頼(セッションの入力)になる。
- **メンションなしで受け取るチャンネルのメッセージ。** エージェントの**メンション時のみ応答**をオフにすると、利用がオンのチャンネルにあるメンションのないトップレベルのメッセージも作業の依頼になる(会話スイッチが `off` か `shadow` のとき)。
- **判断バッファに置くメッセージ。** エージェントの会話スイッチが上がっているときだけ置く。スイッチはワークスペースの owner・admin か運用者が上げる。聞き取り設定がすべてのメッセージ(`free`)のチャンネルにあるメンションのないメッセージと、エージェントが最近関与したが作業に結び付いていないスレッドの返信である。エージェントが割り込むかを判断する間、一時的に置く。スイッチが上がると、エージェントはすべてのメッセージを聞くチャンネルごとにそのことを知らせる投稿を一度する(告知の版が変わって改めて知らせる必要があれば、その版でもう一度)。

## 保存するものと削除するタイミング

| 何を | 含むもの | 削除するタイミング |
| --- | --- | --- |
| 判断バッファ | 置いたメッセージの本文、メッセージの位置(team、チャンネル、ts)、書いた人の Slack id | 判断が終わるとすぐに削除する。判断できなかったメッセージは置いてから10分後に削除する。メッセージが Slack で削除されたとき、チャンネルがアーカイブ・削除されたとき、ボットがチャンネルを抜けたとき、チャンネルの聞き取りがオフになったときはすぐに削除する |
| 判断記録 | 判断したメッセージの位置と決定、理由コード。メッセージの本文とモデルの回答は含まない | 自動では削除しない |
| チャンネル要約 | エージェントが判断しながら言い換えて書いた行と、その出典メッセージの位置・話者。原文は写さない。判断したメッセージを40文字を超えてそのまま写した行は書かない | 現在の版は残る。古い版は直近7日の間に現在の版だったものだけが残る。出典メッセージが Slack で削除されるとその行を、編集されると編集前の本文で作った行を削除する。チャンネルが削除されると、そのチャンネルの要約をすべて削除する |
| 関与記録 | エージェントが関与したメッセージの位置と種類(メンション、返信など)。本文は含まない | 自動では削除しない |
| 作業の依頼(セッションの入力)とセッション記録 | 依頼として受け取ったメッセージの本文、エージェントの回答、セッションイベント | 今は期限なく残る |
| セッションのメタデータ | セッション id、時刻、コスト台帳、監査記録(receipt) | 残る |

組織の管理者が依頼すれば、運用者がチャンネルの会話ひとつの関与記録、チャンネル要約、判断バッファを削除できる。方法は[会話記録の管理者削除](/run-server/self-hosting/reference/storage#会話記録の管理者削除)にある。

## まだないもの

- 作業の依頼(セッションの入力)の保存期間はまだ決めていない。保存期間が決まったら、この文書に書く。
- 今は、アプリを削除しても保存された記録は自動では削除されない。
