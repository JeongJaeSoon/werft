## 학습

Werft는 Slack에서 읽은 글로 어떤 AI 모델도 학습시키지 않는다.

에이전트는 이 조직이 연결한 모델 키로 모델을 부른다. 모델에 보낸 글은 그 모델 제공자의 데이터 정책을 따른다.

## 읽는 글

- **에이전트에게 한 요청.** 에이전트를 멘션한 글, 에이전트에게 보낸 DM(**DM 받기**를 켠 경우), 에이전트의 작업(세션)이 이어지는 스레드에 쓴 글은 작업 요청(세션 입력)이 된다.
- **멘션 없이 받는 채널 글.** 에이전트의 **멘션했을 때만 반응**을 끄면, 사용이 켜진 채널의 멘션 없는 최상위 글도 작업 요청이 된다.- **판단 버퍼에 담는 글.** 에이전트의 대화 스위치가 올라가 있을 때만 담는다. 스위치는 워크스페이스 owner·admin이나 운영자가 올린다. 듣기 설정이 모든 글(`free`)인 채널의 멘션 없는 글과, 에이전트가 최근 관여했지만 작업에 묶이지 않은 스레드의 답글이다. 에이전트가 끼어들지 판단하는 동안 잠깐 담는다. 스위치가 올라가면 에이전트는 모든 글을 듣는 채널마다 그 사실을 알리는 글을 한 번 올린다(고지 판이 바뀌어 다시 알려야 하면 그 판에서 다시 한 번).

## 저장하는 것과 지우는 때

| 무엇 | 담는 것 | 지우는 때 |
| --- | --- | --- |
| 판단 버퍼 | 담은 글의 본문, 글의 자리(team, 채널, ts), 쓴 사람의 Slack id | 판단이 끝나면 바로 지운다. 판단하지 못한 글은 담긴 지 10분 뒤에 지운다. 글이 Slack에서 지워지거나, 채널이 보관·삭제되거나, 봇이 채널을 나가거나, 채널의 듣기가 꺼지면 바로 지운다 |
| 판단 기록 | 판단한 글의 자리와 결정, 이유 코드. 글의 본문과 모델의 답은 없다 | 자동으로 지우지 않는다 |
| 채널 요약 | 에이전트가 판단하며 풀어 쓴 줄과 그 출처 글의 자리·화자. 원문을 옮기지 않는다. 판단한 글을 40자 넘게 그대로 옮긴 줄은 쓰지 않는다 | 지금 판은 남는다. 옛 판은 지난 7일 안에 지금 판이었던 것만 남는다. 출처 글이 Slack에서 지워지면 그 줄을, 고쳐지면 고치기 전 본문으로 만든 줄을 지운다. 채널이 삭제되면 그 채널의 요약을 모두 지운다 |
| 관여 기록 | 에이전트가 관여한 글의 자리와 종류(멘션, 답글 등). 본문은 없다 | 자동으로 지우지 않는다 |
| 작업 요청(세션 입력)과 세션 기록 | 요청으로 받은 글의 본문, 에이전트의 답, 세션 이벤트 | 지금은 기한 없이 남는다 |
| 세션 메타데이터 | 세션 id, 시각, 비용 원장, 감사 기록(receipt) | 남는다 |

조직 관리자가 요청하면 운영자가 채널 대화 하나의 관여 기록, 채널 요약, 판단 버퍼를 지울 수 있다. 방법은 [대화 기록의 관리자 삭제](/run-server/self-hosting/reference/storage#대화-기록의-관리자-삭제)에 있다.

## 아직 없는 것

- 작업 요청(세션 입력)의 보존 기간은 아직 정하지 않았다. 보존 기간이 정해지면 이 문서에 적는다.
- 지금은 앱을 지워도 저장된 기록이 자동으로 지워지지 않는다.
