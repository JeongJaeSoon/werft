<Callout type="warn">
Attaching files to a message is not available yet. A message body is a single UTF-8 text string of up to 32,768 bytes.
</Callout>

The only required field of `sessions.messages.send` (`POST /v1/sessions/{id}/messages`) is the text `message`. There is no field to carry a file. If the length is exceeded, the response is 413.

<Tabs groupId="client" persist items={["SDK", "HTTP API"]}>
<Tab>

```ts
import { isApiError } from "@werft-ai/sdk";

try {
  await werft.sessions.messages.send(sessionId, { message: "a".repeat(32_769) });
} catch (error) {
  if (isApiError(error)) console.log(error.status, error.code);
  else throw error;
}
```

```text
413 PAYLOAD_TOO_LARGE
```

</Tab>
<Tab>

```bash
LONG=$(head -c 32769 /dev/zero | tr '\0' a)
curl -sS -o /dev/null -w '%{http_code}\n' "$API/v1/sessions/$SID/messages" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --arg m "$LONG" '{message: $m}')"
```

```text
413
```

Reference: [`POST /v1/sessions/{id}/messages`](/reference/http-api/messages-and-turns/appendSessionMessage)

</Tab>
</Tabs>

Commit the files the agent needs to read to the repository the session uses, and point to them by path in the message. A session that starts with a repository clones it when it starts. An agent session that starts without one can read the files only after the agent attaches that repository.
