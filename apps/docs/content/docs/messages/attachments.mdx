---
title: "첨부"
description: 메시지에 파일을 붙이는 기능의 지금 상태
---

<Callout type="warn">
메시지에 파일을 붙이는 기능은 아직 없다. 메시지 본문은 UTF-8 텍스트 하나이고 32,768바이트까지다.
</Callout>

`sessions.messages.send`(`POST /v1/sessions/{id}/messages`)의 필수 필드는 텍스트 `message` 하나다. 파일을 실을 필드는 없다. 길이가 넘치면 413이다.

<Tabs groupId="client" persist items={["SDK", "HTTP API"]}>
<Tab>

```ts
import { isApiError } from "@werft-ai/sdk";

try {
  await werft.sessions.messages.send(sessionId, { message: "a".repeat(32_769) });
} catch (error) {
  if (isApiError(error)) console.log(error.status, error.code);
  else throw error;
}
```

```text
413 PAYLOAD_TOO_LARGE
```

</Tab>
<Tab>

```bash
LONG=$(head -c 32769 /dev/zero | tr '\0' a)
curl -sS -o /dev/null -w '%{http_code}\n' "$API/v1/sessions/$SID/messages" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --arg m "$LONG" '{message: $m}')"
```

```text
413
```

레퍼런스: [`POST /v1/sessions/{id}/messages`](/reference/http-api/messages-and-turns/appendSessionMessage)

</Tab>
</Tabs>

에이전트가 읽어야 할 파일은 세션이 쓰는 저장소에 commit해 두고, 메시지에서 경로로 가리킨다. 시작 저장소가 있는 세션은 시작할 때 그 저장소를 clone한다. 저장소 없이 시작한 에이전트 세션은 에이전트가 그 저장소를 attach해야 파일을 읽을 수 있다.
